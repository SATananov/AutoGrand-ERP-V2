# Clean Export Checkpoint — Step 3.5 Transfer Print Document / Transfer Slip

## Статус

Готов clean checkpoint за Step 3.5.

## Съдържание

Step 3.5 добавя печатен трансферен документ за складовите трансфери:

- печатен route `/stock/transfer/:documentId/print`;
- чист standalone print view;
- A4 print CSS;
- бутони `Печат` в Transfer Center;
- бутон `Печатен документ` в картата на трансфера;
- реално поведение за `Приеми и печат` — приема документа и отваря печатния лист;
- визуален документ със статус, маршрут, артикули, коментар, движения и подписи.

## UX принцип

Документът е направен за бърза работа в обект: служителят приема или отваря трансфер, натиска печат и получава четим трансферен лист без да търси допълнителни екрани.

## Без промени в база данни

Няма нова Prisma таблица и не е нужен `npm run db:generate`.
