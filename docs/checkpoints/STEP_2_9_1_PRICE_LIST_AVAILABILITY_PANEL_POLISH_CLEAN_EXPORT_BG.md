# Clean Export Checkpoint — Step 2.9.1 Price List Availability Panel Polish

## Checkpoint

AutoGrand ERP V2 Step 2.9.1 полира работния екран за артикули, цени и наличности. Долната зона вече се използва за наличности по обекти, заявки към моя обект, мои заявки и история.

## Проверки

Очаквани проверки:

```powershell
node scripts/check-project.mjs
node --check src/server.js
node --check src/services/price-list-workbench-service.js
node --check public/js/app.js
node --check public/js/erp-v2-workspace-manager.js
npm run dev
```

## Какво да се тества

1. От меню Продажби → Ценова листа да се отвори екранът.
2. При избор на артикул долната зона да се сменя за избрания артикул.
3. Таб „Наличности по обекти“ да показва имената на обектите в широка таблица.
4. Цветовете да подсказват състояние: свободно, малко, няма свободно, чака действие.
5. Таб „Заявки към моя обект“ да показва меки червени редове, когато има чернова трансфер от текущия обект към друг обект.
6. Таб „Моите заявки“ да показва заявки, които текущият обект очаква от друг обект.
7. Десният панел да остане кратък: снимка, бързи действия и легенда.

## Бележка

Пълната логика за отделна transfer request queue остава за следваща стъпка. Тази стъпка подрежда UX и използва наличните трансферни документи като сигнали.
