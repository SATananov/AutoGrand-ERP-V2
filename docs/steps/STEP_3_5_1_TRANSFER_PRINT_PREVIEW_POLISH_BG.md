# Step 3.5.1 — Transfer Print Preview Polish

Финален polish върху печатния трансферен документ.

## Какво добавя

- Реално AutoGrand лого в горната част на документа.
- По-чист preview: командната лента вече не закрива печатния лист.
- Заглавие „Трансферен документ“ с отделен тип/статус на документа.
- Таблица с доставна цена и продажна цена с ДДС.
- Общи стойности по доставна цена и по продажна цена с ДДС.
- Автоматично попълване на служител при предаване/приемане според текущия ERP потребител.
- По-добър вътрешен print note за доставните цени.

## UX правило

Печатният документ остава вътрешен ERP документ. Доставните цени са служебна информация и са показани само в този вътрешен трансферен документ.
