# AutoGrand ERP V2 — Step 2.1

## Име
Sales Line Edit/Delete + Document Safety

## Какво добавя
- Редакция на ред: количество / цена / отстъпка
- Изтриване на ред
- Автоматично преизчисляване след edit/delete
- Заключване на редовете при POSTED документ
- Заключване на редовете при CANCELLED документ
- Moneta-like warning banner за заключени документи

## Проверка
1. Отвори чернова документ
2. Добави ред
3. Редактирай количество/цена/отстъпка
4. Изтрий ред
5. Натисни Осчетоводи
6. Провери, че редовете вече са заключени
7. Върни Чернова и провери, че редакцията пак е активна
