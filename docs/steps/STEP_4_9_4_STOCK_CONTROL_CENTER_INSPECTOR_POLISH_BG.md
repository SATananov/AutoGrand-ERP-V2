# Step 4.9.4 — Stock Control Center Inspector Polish / Cross-links / Print-ready QA

## Цел

Тази стъпка полира вече стабилния Step 4.9.3 Detail Inspector, без да променя складовата бизнес логика.

## Добавено

- Moneta-like toolbar върху inspector страницата.
- Бърз линк назад към Stock Control Center.
- Линк към read-only API trace за същия inspector контекст.
- Print / QA бутон.
- Copy reference бутон за операторска комуникация.
- Автоматични read-only/status badges.
- Print-ready CSS за по-чист QA изглед.
- Smoke check за новия UI слой.

## Ограничения

- Няма директна редакция на stock movement journal.
- Няма unlock на POSTED документи.
- Няма inline reversal/correction.
- Няма промяна на Step 4.8 posting/reversal логика.
- Всички действия са read-only UI/cross-link/print помощни действия.
