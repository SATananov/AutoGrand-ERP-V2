# Step 3.4 — Transfer Center Polish + Status Counters

Цел: да завършим ежедневната работа в „Трансфери и заявки“ така, че служителят бързо да вижда какво чака действие, какво пътува, какво е получено и къде има проблем.

## Добавено

- по-ясни табове по текущ обект:
  - Заявки към текущ обект
  - Заявки от текущ обект
  - Пътува към текущ обект
  - Пътува от текущ обект
  - Получени в текущ обект
  - Липса на рафт
  - История
- статусен поток над табовете: Заявка → Проверка на рафт → В път → Приемане → Получено → Проблем;
- „Бързи действия“ с най-важните редове за текущия обект;
- картите в „Складов център“ отварят конкретния таб с `?tab=`;
- коментарът към трансфера се вижда във всички основни таблици;
- по-добър AutoGrand toast при изпращане, приемане, печат placeholder, липса и връщане;
- message за `stock_transfer_in_transit`.

## UX правила

- червено = действие от текущия обект;
- синьо = В път / чакаме;
- жълто = чака приемане;
- зелено = получено / приключено;
- меко червено = липса / проблем.

## Без промяна

- няма нова Prisma таблица;
- няма нужда от `npm run db:generate`;
- реалният печатен документ остава за следваща стъпка.
