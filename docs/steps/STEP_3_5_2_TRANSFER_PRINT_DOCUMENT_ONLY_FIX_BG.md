# Step 3.5.2 — Transfer Print Document Only Fix

## Цел

Поправя печата на трансферния документ така, че при натискане на **Печат** да се печата само самият трансферен лист, а не целият ERP екран с меню, ribbon, табове и статусбар.

## Промени

- Печатният изглед получава собствен `data-print-url`.
- Ако печатният документ е отворен вътре в AutoGrand работния прозорец, бутонът **Печат** печата скрит чист iframe с директния печатен route.
- Ако печатният документ е отворен като самостоятелна страница, се използва нормален `window.print()`.
- Добавена е поддръжка за `autoprint=1`.
- Поправен е print CSS блокът и са добавени допълнителни print правила за скриване на ERP shell елементи.

## Резултат

Печатният preview трябва да показва само A4 трансферния документ.
