# Step 3.5.3 — Transfer Print Forms and Preview Dialog

## Цел

Да се доближи печатът на трансферен документ до реално ERP поведение: първо избор на печатна форма и принтер профил, после преглед и чак тогава реален печат.

## Добавено

- Нов прозорец „Избор на печатна форма“ в печатния трансферен документ.
- Печатни форми:
  - Трансферен документ — компактен;
  - Трансферен документ — с цени;
  - Трансферен документ — подробен;
  - Текстов печат / складов лист.
- Принтер профили:
  - Складов принтер A4;
  - Офис принтер;
  - Етикетен принтер;
  - PDF / архив.
- Брой копия.
- Отметка „Преглед преди печат“.
- Компактен layout за документи с много артикули.
- Запазва AutoGrand визуалния стил, но позволява повече редове на една страница.

## Технически бележки

- Няма промяна в Prisma схемата.
- Принтер профилите засега са работни ERP настройки, не директни Windows printer paths.
- Реалното свързване към локални/мрежови принтери остава за бъдещ local print service / desktop helper.
