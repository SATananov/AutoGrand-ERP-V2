# Step 2.8 — Stock Adjustment Document Card

## Цел

Добавя реален ERP документ за складови корекции вместо директно еднократно действие.

## Обхват

- Нови Prisma/SQL модели:
  - `StockAdjustmentDocument`
  - `StockAdjustmentLine`
- Нов документ за складова корекция в статус **Чернова**.
- Карта на складова корекция с табове:
  - Редове
  - Складови движения
  - История
  - Бележки
- Редове към документа с посока:
  - Вход / увеличение
  - Изход / намаление
- Типове корекция:
  - Начално салдо
  - Излишък
  - Корекция вход
  - Корекция изход
  - Липса
  - Брак
- Публикуване на документа:
  - проверява наличност за изходящи редове;
  - създава `StockMovement`;
  - обновява `StockBalance`;
  - заключва документа.
- Отказ на документа:
  - заключва документа без складови движения.
- Нов browse екран `stock-adjustments` / **История корекции**.

## Правило

Складова наличност не се променя при създаване на чернова. Наличност се променя само при публикуване.
