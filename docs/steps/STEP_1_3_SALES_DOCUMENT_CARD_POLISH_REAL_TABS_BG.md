# AutoGrand ERP V2 — Step 1.3

Sales Document Card Polish + Real Tabs

## Какво добавя
- Документната карта връща към правилния source екран
- Реални tabs: Редове / Плащания / История / Бележки
- Lines toolbar: Добави ред / Изтрий ред / Избери артикул / Преизчисли
- По-компактен десен панел
- Workflow информация по тип документ
- По-подреден Moneta-like документен layout

## Проверка
1. Отвори `/screen/offers`
2. Отвори карта
3. Провери tabs:
   - Редове
   - Плащания
   - История
   - Бележки
4. Натисни Назад — трябва да върне към `/screen/offers`
