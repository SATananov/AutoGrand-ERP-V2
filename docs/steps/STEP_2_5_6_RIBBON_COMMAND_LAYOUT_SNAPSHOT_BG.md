# Step 2.5.6 — Ribbon Command Layout + Snapshot

## Цел

Да се подреди горната командна лента по Moneta-подобна ERP логика, но със собствена AutoGrand визия, без добавяне на нова ERP бизнес логика.

## Направено

- Добавени са логически групи: Печат и преглед, Клипборд, Документ, Запис, Списък и изглед, Обмен, Навигация.
- Премахнато е объркването от повтарящи се лупи — „Преглед“, „Филтър“, „Покажи всички“ и „Опресни“ вече имат различни визуални знаци.
- Добавен е бутон „Снимка“ в група „Клипборд“.
- „Снимка“ използва browser Screen Capture API: потребителят избира екран/прозорец/таб, след което изображението се копира в клипборда, ако браузърът позволява.
- Ако браузърът не позволи копиране на PNG в клипборда, снимката се изтегля като PNG fallback.

## Важно

Не са добавяни нови операции за продажби, доставки, склад, Prisma или база. Повечето ribbon бутони остават command placeholders със статус съобщение, докато реалната логика бъде планирана в отделни стъпки.
